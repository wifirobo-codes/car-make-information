# 🚗 Car Make Information App (APK)

An Android APK app made using Thunkable that uses your **camera** + **Teachable Machine model** to identify the **car make/model** (like **Baleno**, **Fronx**, etc.), then shows detailed specs from a connected Airtable dataset.

MediaFire Download Link : https://www.mediafire.com/file/bzi8wnltlzlsgsw/Car+Make+Finder-v1-release.apk/file

---

## ✨ Features

- 📸 **Camera-based car recognition**
  - Point your camera at a car.
  - The app predicts the car make/model using a Teachable Machine model.

- 🧠 **Teachable Machine integration**
  - Model powered by **Google Teachable Machine**.
  - The attached **`.tm` file** contains the trained model/project setup used for predictions.

- 🔎 **Search tab with car list**
  - After detection, go to the **Search** tab.
  - View a list of cars pulled from Airtable.

- 📋 **Detailed car specifications**
  - Tap any car name to see details like:
    - Engine
    - Cylinders
    - and other vehicle information.

## 🚀 How to Use

1. Install and open the APK.
2. Use the camera screen to detect the car.
3. Let the model identify the make/model.
4. Open the **Search** tab.
5. Select a car from the list.
6. View full specs and details.
